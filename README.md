# DAA Mini Project

## Project Title
Implementation and Analysis of Rabin-Karp Algorithm for Cybersecurity Threat Detection

## Algorithm
Rabin-Karp Algorithm

## Programming Language
C

## Description
This project implements the Rabin-Karp string matching algorithm and demonstrates its application in cybersecurity threat detection by identifying suspicious keywords such as malware, trojan, phishing, virus, and ransomware within textual logs and messages.

## Time Complexity
Average Case: O(n + m)
Worst Case: O(nm)

## Space Complexity
O(1)
